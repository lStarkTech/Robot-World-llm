Robot World-LLM: A game prototype

Welcome to Robot World-LLM, a lightweight, custom-built game environment designed to explore the frontier of LLM-driven gameplay mechanics.

Instead of using a commercial engine, I built this environment from scratch to demonstrate how a Small Language Model (SLM) can act as a real-time "co-developer" within a sandboxed world.
The Vision
As LLMs emerged a question was on my mind: how far can they go? What if instead of being applied as a simple NPC, they were used as a "master" of the game world, able to create something new based on the requests of the player?
Goal was to move beyond "NPC Chat" and test if an LLM could effectively manipulate game logic through natural language, while maintaining the integrity of the codebase.
Key Technical Features

    Custom Game Core: Developed a minimalist engine featuring:

        Collision System: Precise hit-box detection and response.

        Multi-Scene Architecture: Seamless movement between 3 distinct, explorable maps via interactive door triggers.

    Integrated LLM Pipeline: The model is baked directly into the application flow. On startup, the prototype initializes the language model, ready to receive instructions.

    Natural Language Coding (Terminal-Based): * Users can chat with the model via an integrated terminal.

        The model interprets requests for "trivial" functionality additions (e.g., “Make the player jump” or “Enable horizontal movement”).

    The "Safety Guard" (Syntax Validator): * To prevent the game from crashing, I implemented a validation layer.

        Outcome: Any code generated by the LLM is parsed and rejected if it fails syntactical or structural checks before it ever touches the runtime.

Tech Stack

    Language: I wrote the code entirely in python, using the libraries Pygame, Ollama and Langchain mainly to integrate the whole system.

    AI Integration: Since the goal was to run the model locally, I tried out different small models that were released at the time such as Gemma-4b, Hermes-8b, all were tested on the game to        see how goodly they worked out on simple functions.

    Logic: Custom-built collision and state management.

How It Works

    Exploration: To even initially explore the maps, LLM are the first resource, you need to ask everything in order to make every move and decision!

    Interaction: Open the terminal to "talk" to the game world.

    Real-time Evolution: Request a feature. If the LLM generates valid code, the character's capabilities expand instantly. If the LLM hallucinates or makes a typo, the Safety Guard catches it,     keeping the game stable.
